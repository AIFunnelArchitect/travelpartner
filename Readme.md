# Travel Website

## About the Project

This is a travel website built using **HTML and CSS** as part of my journey into web development. The project helped me apply my knowledge of HTML for structuring web pages and CSS for styling and creating an attractive layout.

The website showcases travel related information, including destinations, outdoor adventures, business travel spots, and Asian cuisine.

## Features

- Travel destination and activity listings.
- Sections highlighting outdoor adventures and business travel spots.
- Information about Asian cuisine.
- Clean layout and styling using CSS.
- Responsive layout techniques and Flexbox for arranging content.

## Technologies Used

- **HTML5** – For structuring the website content.
- **CSS3** – For styling, layout, spacing, and visual presentation.
- **Flexbox** – For creating flexible page layouts.

## What I Learned

Through this project, I practiced:

- Structuring web pages using HTML.
- Applying CSS properties for layouts, spacing, and styling.
- Using Flexbox to arrange elements.
- Organizing website content into different sections.
- Applying my web development knowledge to build a complete website.

## Purpose

This project is part of my learning journey in front-end web development. It represents a step toward building more interactive and functional websites as I continue learning new technologies.
